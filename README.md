# Portafolio personal | Christian Benitez

Mi portafolio personal: una página con presentación, sobre mí, proyectos y contacto. Lo hice con HTML y Tailwind CSS como parte de mi formación en desarrollo web en Riwi.

- Sitio publicado: https://christian-b1998.github.io/portafolio/
- Repositorio: https://github.com/christian-b1998/portafolio.git

## Qué contiene

- **Presentación:** quién soy y a qué me dedico.
- **Sobre mí:** mi formación (administración de negocios e ingeniería de software) y las tecnologías que estoy aprendiendo.
- **Proyectos:** tres tarjetas con enlace a Rueda Libre, Riwi Task Manager y este mismo portafolio.
- **Contacto:** formulario con nombre, correo y mensaje.

## Tecnologías

- HTML5 con etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Tailwind CSS 3.4.17, cargado por CDN.
- Fuentes de Google Fonts: Bricolage Grotesque y DM Sans.
- Sin JavaScript propio.

## Qué practiqué con Tailwind

- Clases utilitarias de espaciado, color y tipografía.
- Flexbox y grid para la maquetación.
- Diseño responsive con el prefijo `md:`: las tarjetas y el contacto pasan de una columna en celular a varias en escritorio.
- Estados `hover:` y `focus:` en enlaces, botones y campos del formulario.
